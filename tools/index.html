怎么使用这个看板？

① 网页应用：点击“打开计算器”，直接进入交互页面，手机也可用。

② GitHub Actions：点击“查看工作流”，登录 GitHub 后由你自行决定是否点击 Run workflow。这里只是跳转入口，不会自动启动任务。

③ 限制/归档：黄色卡片通常处于试验、只读或停写状态；红色归档任务不可当成生产扫描。仓库里出现工作流文件，不代表程序已正常部署或当前具备运行配额。

④ 本地 V4 Runner：本工具台不直接控制你的电脑或本地计划任务。要实现安全的一键远程运行，需要单独授权的服务，本版没有安装。
